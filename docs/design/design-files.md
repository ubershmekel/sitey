# Design files

Features in Sitey should be designed first, implemented later.

The files in this folder should each describe:

- A piece of tech, user experience, or requirement
- Why we need it
- URLs and endpoints it relies on
- Which files implement it

When there is a gap between the design and code - a human should be asked
whether to fix the design or the code. The design files should mainly be used to
serialize developer intent.
